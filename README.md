## Versioning

Each skill carries its own `metadata.version` in `SKILL.md` frontmatter. Suites release together with matching versions; the release tag is suite-grain (`<suite>-v<semver>`) when a suite exists, skill-grain (`<skill>-v<semver>`) otherwise.

## Spec conformance

Every PR validates against the Agent Skills spec via `agentskills validate`. See `.github/workflows/validate.yml` (added in U4).
